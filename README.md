# Audit & Enhance for Moodle

A site health audit for Moodle: security and configuration, performance and storage, site hygiene, accessibility and
plugin risk, with an overall score and clear fix steps for every finding.

Status: in development. See [docs/SPEC.md](docs/SPEC.md).

Installs as `local/auditenhance`. Moodle 4.5 to 5.3, PHP 8.1+.
